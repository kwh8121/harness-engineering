# eval 입력 01

프로필 페이지 저장 버튼 색상이 회색인데 브랜드 파란색으로 바꿔줘.

(대상 프로젝트: Next.js 15 + TypeScript + Tailwind. `npm run lint`, `npm run typecheck`,
`npm run test`, `npm run build` 가 모두 설정되어 있다. 색상 토큰이 `tailwind.config.ts` 에
`brand.blue` 로 이미 정의되어 있고, 저장 버튼은 `components/profile/SaveButton.tsx` 한 파일에만 있다.
이 버튼을 쓰는 다른 화면은 없다.)
