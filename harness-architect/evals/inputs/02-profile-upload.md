# eval 입력 02

사용자 프로필 페이지에 프로필 이미지 업로드 기능을 추가해줘.

(대상 프로젝트: Next.js 15 + TypeScript + Supabase. `npm run lint`, `npm run typecheck`,
`npm run test`, `npm run build` 설정됨. 업로드는 프론트엔드 폼, `app/api/profile/avatar/route.ts`
API 핸들러, Supabase Storage 버킷 세 곳을 거친다. 세 곳은 하나의 업로드 흐름으로 이어져 있어
한쪽만 먼저 완성해도 동작을 확인할 수 없다. 기존 프로필 저장 기능과 그 테스트가 이미 있다.
로컬 개발 환경에서만 작업한다.)
