# eval 입력 03

인증 시스템을 JWT 에서 OAuth 기반으로 전환하면서 기존 세션과 DB 도 마이그레이션해줘.

(대상 프로젝트: Next.js 15 + TypeScript + PostgreSQL. 운영 중인 서비스이고 실사용자가 있다.
JWT 발급·검증·리프레시가 `lib/auth/` 아래 여러 파일에 흩어져 있으며, 리프레시 토큰 경로를
어디서 호출하는지 전부 파악되어 있지 않다. 세션 저장소 스키마와 users 테이블이 외래키로 엮여 있다.
기존 로그인 사용자의 세션을 끊으면 안 된다. 인증 관련 테스트는 일부만 있다.
작업 결과는 프로덕션에 배포할 예정이다.)
