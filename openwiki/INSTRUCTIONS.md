A code wiki for this repository.

## 저장소 성격

이 저장소는 단일 애플리케이션이 아니라, 책 **《하네스엔지니어링 with Claude Code》**의 실습 예제 모음이다.
Claude Code를 "한 번의 대화를 잘 굴리는 도구"가 아니라 "작업 환경(하네스)을 미리 세팅해두는 도구"로
다루는 방법을 챕터·절 단위로 보여주는 것이 목적이다.

- 최상위의 `ex-XX-YY-이름/` 폴더 각각이 **독립적인 예제**다. 서로 다른 예제를 하나의 통합 아키텍처로
  묶어서 설명하지 말 것 — 예제 간 코드 재사용이나 의존 관계는 의도된 것이 아니라 우연의 일치다.
- 각 예제 폴더 이름의 `XX`는 책의 장(chapter), `YY`는 절/순번을 의미한다. 문서화할 때는 해당 예제가
  어느 장의 어떤 개념(에이전트 도구 경계, 스킬 분리 신호, PR 리뷰 오케스트레이션, 다중 에이전트 팀,
  의존성 분석, 안전장치 등)을 보여주기 위한 것인지 함께 밝힐 것.
- 예제 대부분은 프로덕션 코드가 아니라 **개념 실증(demo)**이다. 일부는 기본적으로 mock/dry-run으로
  동작하고 `USE_LIVE_LLM=1` 같은 옵트인 플래그로만 실제 LLM을 호출한다 (예: `ex-13-01-dependency-mapper`).
  이런 예제를 마치 실서비스 코드처럼 서술하지 말고, mock 기본값과 실제 호출 옵션을 구분해서 밝힐 것.
- 각 예제 폴더에는 자체 `README.md`가 있고 그것이 해당 예제의 1차 근거다. 이 위키는 그것을 대체하는
  것이 아니라, 장/절 간 관계와 전체 구조를 빠르게 훑어볼 수 있는 보조 지도 역할만 한다.
- `docs/superpowers/`, 루트 `.claude/`(skills, agents 등)는 독자에게 보여줄 예제 결과물이 아니라,
  이 저장소 자체를 만들고 검수하는 데 쓰인 **메타 작업 도구/기록**이다. 예제 인덱스와 같은 층위로
  섞어서 문서화하지 말 것.
